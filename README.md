# brgnetuse

Command-line toolkit for managing Linux networking, secure tunnels, firewall, and NAT configuration.

The project provides utilities for managing network interfaces, tunnel configurations, routing-related operations, firewall rules, and NAT settings.

The tools are designed for Linux-based network infrastructure environments and automate common operational tasks around secure connectivity.

## Features

* Network interface management
* WireGuard and AmneziaWG configuration operations
* Peer management
* IP address configuration
* Firewall rule management using iptables
* NAT rule management
* IPv4 and IPv6 forwarding control
* Network configuration inspection
* Command-line based administration

## Components

### brgsetwg

Utility for configuring network interfaces and connectivity settings.

Capabilities:

* interface management
* peer configuration
* IP address management
* NAT configuration
* firewall operations
* forwarding control

### brggetwg

Utility for retrieving network configuration information.

Capabilities:

* interface information
* peer information
* IP configuration
* firewall rules
* NAT rules
* forwarding status

## Requirements

* Linux
* iproute2
* iptables
* WireGuard tools / AmneziaWG tools

Documentation and usage examples are being expanded.
